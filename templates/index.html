Architecture

User (WhatsApp)
      │
      ▼
FastAPI Webhook (/webhook)
      │
      ▼
Intent Parser (app/intent_parser.py)
  ├── Regex/keyword rules  (fast, free)
  └── Pidgin + Yoruba normalisation layer
      │
      ▼
Action Backend (app/actions.py)
  ├── CHECK_BALANCE
  ├── BUY_AIRTIME   ← cowriesys/airtime
  ├── BUY_DATA      ← cowriesys/airtime
  ├── SEND_MONEY    ← tomiiide/nigerian-banks
  └── PAY_BILL      (coming in V2)
      │
      ▼
Response Engine (app/response_engine.py)
  ├── Direct action message  (fast path)
  └── LLM: Claude Haiku / GPT-4o-mini fallback
      │
      ▼
WhatsApp Cloud API → User

Quick Setup

# 1. Install dependencies
pip install -r requirements.txt

# 2. Configure environment
cp .env.example .env
# Fill in WHATSAPP_TOKEN and WHATSAPP_PHONE_ID

# 3. Run
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 4. Expose to WhatsApp (dev)
ngrok http 8000
# Then set webhook: https://<your-ngrok>.ngrok.io/webhook
# Verify token: ogaai_verify_2024
